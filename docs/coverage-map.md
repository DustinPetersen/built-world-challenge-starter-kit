## Boundary of a comprehensive reference release

The repository is designed to be broad and useful across the full event workflow. An unlimited inventory of every possible vendor, dataset or technique would become stale and would not establish more practical coverage. The catalog prioritizes relevant candidates, records access constraints, and gives contributors a repeatable way to add sources. Additional repos become useful when data or deployable implementations need separate ownership and release cycles; a split strategy is included.

External inputs needed by a real team—sponsor drawings, expert reference takeoffs, approved code/form requirements, professional review and vendor credentials—are acquisition dependencies for their implementation. They are not silently substituted with invented records in this public resource kit.

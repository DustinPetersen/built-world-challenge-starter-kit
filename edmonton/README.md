# Start in Edmonton

An Edmonton-first path through the Built World Challenge kit. Sources checked **October 15, 2026**. This is an independent volunteer guide; the event briefs, current City requirements and qualified reviewers govern real projects.

## Pick one local workflow

| Challenge | Suggested first demo | Why it is locally grounded |
| --- | --- | --- |
| Building codes | An applicant and reviewer inspect an incomplete alternative-solution package for an Edmonton project | Begin with the City's submission context and Alberta source versions |
| Building codes | An applicant organizes evidence for a proposed exterior wall/cladding assembly | Edmonton's house-application page has specific documentation pathways; validate applicability with a domain reviewer |
| Embodied carbon | An estimator reviews the slab/foundation quantities for one authorized Landmark home plan, then compares a compatible concrete factor | Directly supports the sponsor workflow without requiring an entire automated house model on day one |

These are proposed starting points, not organizer-approved technical solutions. Ask the event team for an appropriate reference case and permission to use the source documents.

## Start here — 15 minutes

1. Read the [local process map](process-map.md): jurisdiction, development permit, building permit and alternative solution are different pieces.
2. Pick a [local scenario](scenarios.md) and one human reviewer.
3. Follow the [Edmonton source shortlist](sources.md), rather than starting with every global API.
4. Try the [municipal-data recipes](open-data.md), or begin with authorized sponsor drawings for takeoff work.
5. Use the [local carbon assumptions guide](carbon-context.md) to define geography and scope.
6. Bring the [mentor questions](mentor-questions.md) to office hours.

## What changes in the product

- Intake asks **which municipality is responsible**, not merely whether a project is in the Edmonton metro area.
- Codes are tied to Alberta edition/printing plus source-specific local requirements.
- Findings link to an applicable form/requirement; the system separates presence from adequacy.
- Carbon factors expose product/plant geography and declared units. Edmonton location alone cannot justify a factor.
- Building-permit records support discovery and market context; takeoff evidence comes from drawings and schedules.
- City-owned-building sustainability procedures are kept separate from requirements for private homes.

The broader [API catalog](../resources/api-catalog.md) remains available when a team needs an implementation component. First validate the local workflow and input, then choose tools.

# Questions to bring to Edmonton office hours

## Codes reviewer / City process expert

1. For this project type, which submission pathway, form and source versions should we demonstrate?
2. Which information gaps repeatedly cause avoidable follow-up?
3. What is a useful distinction between missing, present but unverified, and adequate evidence in your workflow?
4. Can you provide a permissioned example and independently reviewed checklist?
5. Where should the tool flag professional involvement, and who reviews that rule?
6. Which local source should override a stale cached checklist, and how should we record changes?

## Landmark estimator / carbon reviewer

1. Which supplied plan and high-impact element should the first slice support?
2. Which drawing details resolve thickness, assemblies and schedule assumptions?
3. What reference takeoff and tolerance should we use to judge extraction?
4. Which products/factors are approved for this experiment, and what geography is relevant?
5. How do you define the floor-area denominator and exclusions?
6. Which corrections or plan variants create the most rework today?

## Local builder / BILD industry perspective

1. Is this an Edmonton City workflow or another municipality's workflow?
2. Who prepares, reviews and pays for this work?
3. Which task should our demo shorten without increasing reviewer effort?
4. What output would fit an existing handoff?
5. What is the smallest permissioned pilot you would actually try?

Use event-provided introductions. The [BILD Edmonton Metro about page](https://www.bildedmonton.com/about/) explains its regional industry role; it does not mean every member endorses this repository or will supply data. Do not publish interview notes or team-specific material without permission.

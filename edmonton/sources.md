# Edmonton source shortlist

Reviewed October 15, 2026. These links identify source roles; they are not an official legal checklist. City pages intermittently returned fetch errors during research; the search index and municipal data API remained accessible. Reopen the applicable current page before a real submission.

| Source | Use first for | Applicability / caution |
| --- | --- | --- |
| [Built World Challenge](https://edmontonunlimited.com/programs/built-world-challenge/) | Current briefs, sponsor problem and supplied data | Event scope remains primary |
| [Edmonton house application requirements](https://www.edmonton.ca/residential_neighbourhoods/application-requirements-house-permits) | Residential documentation and alternative-solution context | Choose applicable project conditions; this guide is not the form |
| [New commercial building](https://www.edmonton.ca/business_economy/new-commercial-building) | Commercial path and point access block guidance | Professional technical assessment remains separate |
| [Edmonton energy-code requirements](https://www.edmonton.ca/residential_neighbourhoods/energy-code-requirements) | Local energy documentation context | Operational energy and A1–A3 carbon are distinct |
| [Alberta codes and standards](https://www.alberta.ca/building-codes-and-standards) | Selected Alberta code edition/printing | Confirm project applicability and source version |
| [Alberta building STANDATA](https://www.alberta.ca/building-standata) | Relevant provincial notices/interpretations | Track currency and supersession |
| [Safety Codes Council variances](https://www.safetycodes.ab.ca/permits-inspections/variances/) | Variance process and form discovery | No automated approval endpoint is asserted |
| [Edmonton Zoning Bylaw](https://zoningbylaw.edmonton.ca/) | Development/zoning context | Do not confuse zoning variances with code alternatives; recheck current provisions |
| [General Building Permits](https://data.edmonton.ca/d/24uj-dj8v) | Municipal permit context | Primary dataset and API verified; not drawings or engineering evidence |
| [City open-data licence](https://data.edmonton.ca/stories/s/City-of-Edmonton-Open-Data-Terms-of-Use/msh8-if28) | Data use and attribution terms | Dataset metadata points to terms; preserve source attribution |
| [Monthly permit summary](https://www.edmonton.ca/business_economy/licences_permits/monthly-building-permit-summary) | Published city-level construction context | Confirm reporting basis before comparisons |
| [Green buildings and communities](https://www.edmonton.ca/city_government/environmental_stewardship/green-buildings-communities) | City-building sustainability context | Does not make City-owned requirements universal for private homes |
| [Climate adaptation strategy](https://www.edmonton.ca/city_government/city_vision_and_strategic_plan/climate-change-adaptation-strategy) | Design/context research | Not an embodied-carbon factor database |
| [BILD Edmonton Metro](https://www.bildedmonton.com/about/) | Regional industry context and interview hypotheses | No endorsement or data access implied |

For broader tools use the [API catalog](../resources/api-catalog.md). For code/product evidence use the [code-corpus method](../docs/code-corpus-method.md). For published EPD sources use the [factor-matching guide](../docs/factor-matching-method.md).

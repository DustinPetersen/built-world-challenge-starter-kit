# Contributing

Welcome corrections, links, small examples, and alternative approaches. Keep each contribution focused and explain who it helps.

For a resource: include publisher, link, relevance, access/reuse terms, and date checked. For code: include run instructions and a meaningful failure case. For domain guidance: identify whether it is an official requirement, expert interpretation, or proposal.

Do not contribute sponsor plans, private applications, personal details, credentials, copyrighted code books, or scraped datasets without documented permission. The MIT license covers original contributions only; third-party rights remain with their owners.

Before opening a pull request: run the example tests, check local links, review staged files for sensitive content, and describe limitations. Be respectful of new builders and preserve team ownership of project ideas.

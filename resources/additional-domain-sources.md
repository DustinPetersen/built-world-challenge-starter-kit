| Source | Use | Access / applicability |
| --- | --- | --- |

| [Edmonton house application requirements](https://www.edmonton.ca/residential_neighbourhoods/application-requirements-house-permits) | Understand local submission context | Not a universal alternative-solution checklist |

## Acquisition priorities

1. Organizer plan set and expert reference takeoff, with permission for the intended processing.
2. Exact organizer variance template and reviewed completeness criteria.
3. Authorized code corpus with edition/printing and attribution data.
4. Published carbon factor dataset with compatible scope, geography and rights.
5. Broader market/spatial context only after the core workflow works.

Prefer a smaller authoritative, permissioned corpus over a large undifferentiated dump. Keep source records, hashes, versions and rights as data so later contributors can audit them.

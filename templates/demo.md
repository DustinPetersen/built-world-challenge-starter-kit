# Three-minute demo and handoff

1. 20 seconds: user, problem, current friction.
2. 30 seconds: input, permissions, and scope.
3. 60 seconds: end-to-end workflow; open original evidence.
4. 30 seconds: correct an error and show the update.
5. 20 seconds: show one unresolved case and how it is handled.
6. 20 seconds: evaluation results, limitations, next customer test.

Handoff: run instructions; versions; data access; reference cases; known failures; operating cost per case; next owner. Label manual steps and synthetic records on-screen.
